HMAC-SHA256 Lab

A message authentication code proves two things at once: that a message came from someone holding the secret key, and that nobody altered it on the way. Type a message below, seal it, then try changing one character and watch the seal break.

HMAC(K, m) = H( (K′ ⊕ opad) ‖ H( (K′ ⊕ ipad) ‖ m ) )
